## iaas 和 VPS、云主机是一回事吗

严格说，VPS 是 IaaS 最常见的一种形态，但 IaaS 的范围比 VPS 大。NIST 对 IaaS 的定义是：用户可以自助配置处理、存储、网络等基础资源，并在其上部署任意软件（包括操作系统和应用），但不控制底层的物理基础设施。

落到实际购买时，这个区别很直观：

- **VPS**：买到一段固定或可调的 CPU/内存/存储，通常一台虚拟机对应一份套餐，上手最快。
- **完整云平台**：像 OpenStack 这类环境，你可以自己开多台 VM、划私有网络、配路由器和负载均衡器，按资源池总量计费，而不是按“某型号 VM”计费。
